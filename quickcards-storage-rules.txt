QUICKCARDS - FIREBASE STORAGE RULES (add, do not replace)

In the Firebase console go to: Storage -> Rules.
Keep everything that is already there. Paste the block below INSIDE the existing
"match /b/{bucket}/o { ... }" section, next to your other match blocks, then Publish.

    match /quickcards/{allPaths=**} {
      // Nobody reads these directly. The app serves them through signed URLs
      // from /api/quickcards/images, which checks the user's plan on the server.
      allow read: if false;

      // Only admins can upload, only images, max 3 MB each.
      allow write: if request.auth != null
        && request.resource != null
        && request.resource.size < 3 * 1024 * 1024
        && request.resource.contentType.matches('image/.*')
        && firestore.get(/databases/(default)/documents/users/$(request.auth.uid)).data.role == 'admin';

      // Admins can also delete.
      allow delete: if request.auth != null
        && firestore.get(/databases/(default)/documents/users/$(request.auth.uid)).data.role == 'admin';
    }

Note: the first time you publish a rule that uses firestore.get(), the console may ask
you to allow Storage to read Firestore. Click Allow/Confirm.
